# Base ggproto classes for ggpointless

If you are creating a new geom, stat, position, or scale in another
package, you'll need to extend from
[`ggplot2::Geom`](https://ggplot2.tidyverse.org/reference/Geom.html),
[`ggplot2::Stat`](https://ggplot2.tidyverse.org/reference/Stat.html),
[`ggplot2::Position`](https://ggplot2.tidyverse.org/reference/Position.html),
or
[`ggplot2::Scale`](https://ggplot2.tidyverse.org/reference/Scale.html).

## Details

More info at [ggplot2-book.org](https://ggplot2-book.org/)
